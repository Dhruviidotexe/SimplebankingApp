# 🏦 Simple Python Banking App

A beginner-friendly banking application built with **Python** that simulates basic banking operations such as deposits, withdrawals, balance inquiries, and KYC management. The project also includes a simple, responsive frontend built with Python, Flask, HTML, CSS, and JavaScript.

## 📌 Features

- 💰 Check Account Balance
- ➕ Deposit Money
- ➖ Withdraw Money
- 🪪 Update KYC Details
- 📄 View KYC Information
- ✅ Input Validation
- 🌐 Simple Banking Dashboard UI
- 📱 Responsive Design

## 🛠️ Technologies Used

### Backend
- Python
- flask

### Frontend
- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Dhruviidotexe/SimplePythonBankingApp.git
```
### Navigate to the Project

```bash
cd SimpleBankingApp
```

### Install Dependencies
```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

Then open your browser and visit:

```
http://127.0.0.1:5000
```
